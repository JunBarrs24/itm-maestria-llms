# Recursos de la semana 2

| Recurso | Por qué está aquí |
| --- | --- |
| Vaswani, A. et al. *Attention Is All You Need* (2017). https://arxiv.org/abs/1706.03762 | El artículo original. Leer la sección 3 (arquitectura) después de la clase; la figura 1 y la ecuación 1 son las de la sesión. |
| Alammar, J. *The Illustrated Transformer*. https://jalammar.github.io/illustrated-transformer/ | La explicación visual más usada de self-attention. Complementa el ejercicio en papel con diagramas paso a paso. |
| Alammar, J. *The Illustrated GPT-2*. https://jalammar.github.io/illustrated-gpt2/ | Misma narrativa aplicada al modelo decoder-only que usa el notebook. |
| Hugging Face, *Text generation strategies*. https://huggingface.co/docs/transformers/generation_strategies | Documentación de `generate()`: greedy, sampling, temperature, top-k, top-p y sus parámetros. |
| Hugging Face, *Summary of the tokenizers*. https://huggingface.co/docs/transformers/tokenizer_summary | Byte-Pair Encoding y otros esquemas de tokenización, con ejemplos. |
| OpenAI Tokenizer. https://platform.openai.com/tokenizer | Para comparar cómo tokeniza un modelo actual el mismo texto que GPT-2. Útil para la práctica. |
| `../../shared/primers/01-vectores-y-softmax.md` | Notación mínima para leer la fórmula de atención. Leer antes de la sesión. |
| Xiao, G. et al. *Efficient Streaming Language Models with Attention Sinks* (2023). https://arxiv.org/abs/2309.17453 | Opcional. Explica por qué la primera columna de los mapas de atención concentra tanto peso. |
